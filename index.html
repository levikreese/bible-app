How accuracy is protected

  • Scripture text is fetched live from the source for each version. It is never written or recalled by AI.
  • Each chapter is checked: the returned chapter must match the one requested, and verse numbers must run in order. Problems are flagged on screen.
  • Public-domain versions come from bible-api.com. ESV uses Crossway's official API with your key. Copyrighted versions (NKJV, NLT, NIV…) need their publishers' API keys and are not bundled.
  • *Chronological order is approximate, at the book level, and scholars disagree on dating.
  • Cross-references link to OpenBible.info's dataset. Context and commentary are AI prompts you send yourself, and the prompt asks it to flag uncertainty. Treat the output as a study aid and check it against the text.
  • Highlights and labels live in your browser's local storage. Use Export to back them up.
